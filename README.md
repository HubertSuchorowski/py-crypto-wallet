py-crypto-wallet

A Python-based cryptocurrency wallet application for managing digital assets, tracking prices, and performing cryptocurrency exchanges.
Description

py-crypto-wallet is a command-line application that provides a simple and intuitive interface for cryptocurrency wallet management. Built with Python, it integrates with the CoinGecko API to fetch real-time cryptocurrency prices and allows users to manage their digital assets efficiently.
Features

    💼 Wallet Management - View and manage your cryptocurrency holdings
    📊 Real-time Price Tracking - Get current cryptocurrency prices via CoinGecko API
    💱 Exchange Functionality - Perform cryptocurrency exchanges within your wallet
    📈 Interactive Menu - User-friendly command-line interface
    🗄️ Database Support - Store wallet data persistently

Installation

    Clone the repository:

git clone https://github.com/HubertSuchorowski/py-crypto-wallet.git
cd py-crypto-wallet
